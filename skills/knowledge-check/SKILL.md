# Skill: knowledge-check

Offering, preparing and closing out the Knowledge Check exams that end each Discover stage.
The coach never sits the exam and never answers during it. Gate 4 stands: it is sat only when the
learner asks. Everything else here is what the coach offers.

## Offer, every time

At the start of any block whose activity ends in a knowledge check, and again the block before it,
offer the three supports by name. Do not wait to be asked:

1. **Warm-up drill** - retrieval questions from their own notes on the units that felt shaky.
2. **Missed-question harvest** - after the attempt, walk the wrong answers and re-teach into notes.
3. **Readiness call** - say plainly what is not yet solid and whether to sit it now or next block.

The learner decides if any of them happen. The offer itself is not optional.

## Before the attempt

- Run the warm-up from `learner/notes/`, not from the platform. Wrong answers get recorded.
- Confirm the pass mark and attempt rules off the exam landing page, not from memory.
- Remind them: first attempt scores count the same as any other; nerves are not a scoring criterion.

## After the attempt

1. Record the score, time spent and attempt number in `learner/progress.md` while it is fresh.
2. Open the results page, use "Show incorrect answers only", harvest each missed question into the
   lesson's notes file with the correct answer and one line on why. This is the highest-value
   learning moment in the whole stage; never skip it because the exam was passed.
3. If the score was a fail, agree the re-sit plan and put it in `study-plan.md`.

## Known exam mechanics (QA platform)

- Landing: `app.qa.com/exam/landing/<examId>/`; results: `/exam/results/<examId>/<attemptId>/?context_id=<lpId>&context_resource=lp`.
- Results page text carries "passed", "Score n/100", "Time spent", "Answers Correct". Screenshot it
  before navigating away - it is submission evidence.
